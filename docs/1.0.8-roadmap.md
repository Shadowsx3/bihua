## 2. Next highest-value additions, in order

Start here once the 1.0.8 bucket is verified and built.

### 2.1 Confusable-set practice — **Next**

**Why:** visual and radical confusion is a primary bottleneck for character
learners. The app already records `topConfusions`, and the worksheet can print
them, but there is no one-tap practice loop.

**Scope**
- From a card's coach, offer the confusable family after the same stroke error
  twice in a row.
- Add a short contrast drill: two characters, one shared cue, choose or write
  the target.
- Show the pair in Compare with the differing strokes highlighted.
- Use `progressStore.topConfusions` and `CharacterFamily`; no new content table.
- Do not mix brand-new characters with their lookalikes on day one. Interleave
  only after acquisition.

**Acceptance**
- [ ] The same error twice reveals a gentle “practise the pair” action.
- [ ] The drill creates no cards, XP, or review-log rows.
- [ ] The target is never shown before the learner commits, unless they ask for
      the guide.
- [ ] A journey covers a confusion pair and the return path.

**Guardrails:** do not turn confusion practice into a second queue; it is free
practice.

### 2.2 Answer-privacy audit — **Next**

**Why:** every new cue type is a chance to leak the answer. This is cheap and
protects the core review experience.

**Scope**
- Add a debug-only semantics dump for every recall surface.
- Before reveal, fail if any text node contains the target character, a word
  containing it, or the expected reading.
- After reveal, the answer is allowed.
- Cover writing, pronunciation, hints, dictionary practice, and future cue
  types.

**Acceptance**
- [ ] One test entry point that runs every recall surface.
- [ ] Kana and Hangul self-describing meanings stay masked.
- [ ] The audit is debug-only; no release behaviour.
- [ ] The check is documented in the test matrix.

### 2.3 Worksheet self-check and first-page preview — **Planned**

**Why:** print is where handwriting transfers to paper. The studio is strong,
but the learner has no self-check ritual and no preview before export.

**Scope**
- Two tiny hollow circles per character: shape and order.
- A real first-page preview in Compose before export.
- Optional page-range selector for larger sets.
- Keep the printed sheet ink-friendly and readable in greyscale.

**Acceptance**
- [ ] The preview matches the exported first page.
- [ ] Self-check marks do not obscure the model or tracing cells.
- [ ] A4 and Letter both fit without clipping.
- [ ] The PDF page count in the builder matches the file.

### 2.4 Mascot response pass — **Planned**

**Why:** joy is part of the product, not decoration. The new mascot should feel
alive without becoming noisy.

**Scope**
- Blink, peek, and a proud reaction after a clean repair or a finished sheet.
- One reaction per moment; no random chatter.
- Respect reduce-motion and dark theme.
- Keep the writing surface calm; reactions live around the paper.

**Acceptance**
- [ ] Reduce-motion disables idle motion without removing feedback.
- [ ] Reactions do not block the next action.
- [ ] The mascot never covers the writing square or the grade bar.

### 2.5 Cue ladder — **Planned**

**Why:** gradually removing support builds flexible access. The current cue
choice is a flat list, not a ladder.

**Scope**
- Meaning + reading → meaning → reading → word → audio → blank.
- Promotion by successful retrievals and learner choice, never a punitive
  streak.
- Audio-only opt-in with a timed fallback to meaning, then reading; the target
  only after an explicit reveal.
- Keep the mixed mode for people who prefer variety.

**Acceptance**
- [ ] The ladder is visible in Settings with plain descriptions.
- [ ] Audio-only never reveals the target before the learner asks.
- [ ] The learner can step back to more support at any time.
