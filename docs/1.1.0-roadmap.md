# Bihua 1.1.0 roadmap

Status: working document, updated 2026-11-23. 1.0.9 is in Play review; 1.1.0 is
the next development version (versionCode 20).

The app is made by one person in Uruguay. The goal is a small, warm, careful
study tool, not a faceless product. Keep copy plain, keep the paper calm, and do
not add features that make the daily loop heavier.

## Status legend

- **Done** — implemented and checked.
- **Doing** — in progress now.
- **Next** — start after the current pass.
- **Hold** — larger design or content work; do not start yet.

## Done in the 1.1.0 pass

| Item | Status | Notes |
|---|---|---|
| Anki-style writing | Done | Settings → Practice can show the cue, reveal the character, and grade without a canvas. New cards go Meet → Reveal instead of Meet → Trace → Write. |
| Anki-style pronunciation | Done | The same setting can show the reading and grade without typing. |
| Meaning review | Done | Optional character-to-meaning task, off by default. Type a wording, reveal a clean gloss and a real word, then grade. |
| Meaning synonyms | Done | User wordings are stored per character, cleaned, deduplicated, capped, and removable. |
| Meaning data sanitizer | Done | Blank, placeholder, and structural glosses are skipped; example words are filtered too. |
| Anki meaning | Done | The meaning reveal can skip the text field and go straight to Show answer. |
| Optional per task | Done | Writing and pronunciation are independent switches; both default off. |
| Large-text layout | Done | Home Study tools, Compare, and Paper check keep readable titles at 1.5x. |
| Study list import resilience | Done | Windows BOM and nested JSON `name` fields are handled. |
| Study list export failure | Done | A failed save now reports instead of crashing. |
| Long duplicate names | Done | Names stay unique at the 40-character limit. |
| Word practice reset/back | Done | Practise again clears the canvas; the single-word arrow returns to the character. |
| Word queue system back | Done | Back closes the queue instead of leaving the app. |
| Practice target change | Done | A new target starts with clean ink. |
| Widget counts | Done | Skipped and suspended characters are excluded, and widgets refresh on stop. |
| Loading limits | Done | Model downloads and recognition time out with a readable message. |
| Read-aloud first tap | Done | The tap is queued while the voice starts and reports a missing voice. |
| Navigation coverage | Done | `navigation-deep` walks every Settings section, Compare, Paper, Practice picker, study lists, and the study tools sheet. |
| Back from overlays | Done | System back from Paper/Compare restores the character detail; the word queue no longer exits the app. |
| Anki lesson steps | Done | New cards go Meet → Reveal and the step tabs hide Trace. |
| Reveal copy | Done | The pronunciation answer shows the reading, not the raw result object. |
| Human copy | Done | Fewer "Could not" strings, warmer completion text, no S Pen in user-facing copy. |

## Hold

- RWKV, ONNX, Piper, and neural voice support. They were removed before 1.0.8.
  Reintroducing any of them needs a full port, a package plan, and clear store
  wording. Do not add them as a side effect of another feature.
- Streaks, review debt, accounts, cloud sync, and social features.
- Decorative motion or colour under the ink.
