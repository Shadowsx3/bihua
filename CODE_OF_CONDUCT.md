# Code of Conduct

## Our standard

This project is a place to do careful work. Participants are expected to be
respectful, specific, and generous with context. Disagreement is fine; contempt
is not.

Examples of unacceptable behaviour include harassment, personal attacks,
discriminatory language, publishing someone’s private information, and
sustained disruption of technical discussion.

## Scope

This applies to issues, pull requests, discussions, and any space where someone
is representing the project.

## Enforcement

Report concerns privately to the repository owner through GitHub. Reports will
be reviewed in good faith. Maintainers may remove comments, close threads, or
block participants when needed to keep the project usable.

## Attribution

This is a short project-specific code of conduct, not a legal document. It is
inspired by the Contributor Covenant but kept intentionally small.
